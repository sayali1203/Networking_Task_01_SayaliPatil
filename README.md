## Part B: Networking Concepts

### What is an IP Address?
An IP Address is a unique address used to identify a device on a network.

### What is a MAC Address?
A MAC Address is a physical hardware address assigned to a network adapter.

### What is a Default Gateway?
A Default Gateway is the router that forwards traffic from a local network to other networks.

### What is DNS?
DNS converts website names into IP addresses.

### Public IP vs Private IP

Public IP:
Used on the Internet and assigned by an ISP.

Private IP:
Used inside local networks and not directly accessible from the Internet.
